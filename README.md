
# 🌀 RickAndMorty

iOS-приложение на Swift, использующее официальное API Rick and Morty для отображения персонажей и эпизодов.

---

## 📌 Описание

Проект подключается к [Rick and Morty API](https://rickandmortyapi.com/), получает данные о персонажах и эпизодах, отображает их через таббар.

**Реализовано**  
- Список персонажей с бесконечной подгрузкой (paging)  
- Переход к детальной информации о персонаже  
- Таббар с вкладками: «Персонажи» и «Эпизоды»  
- Загрузка и отображение эпизодов

**Запланировано / ошибки**  
- Кнопка для подгрузки следующей страницы списка персонажей  
- Настройка шрифтов и цветовой схемы  
- Форматирование даты создания персонажа  
- Добавление детального экрана эпизода

---

## 🛠 Технологии и архитектура

- Язык: Swift  
- Платформа: iOS (Xcode проект)  
- Архитектура: MVC / MVVM  
- Сетевые запросы: `URLSession`  
- Декодирование JSON: `Codable`  
- Интерфейс: `UIKit`, `UITableView`, `UITabBarController`

---

## 🚀 Установка и запуск

1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/Sav1taRG/RickAndMorty.git
   cd RickAndMorty
   ```
2. Откройте проект в Xcode:  
   ```bash
   open RickAndMorty.xcodeproj
   ```
3. Соберите и запустите приложение на симуляторе или устройстве (iOS 13+).

---

## 📚 Использование

- Вкладка «Characters»: список персонажей с возможностью пролистывания  
- Тап по персонажу открывает детальный экран  
- Вкладка «Episodes»: список эпизодов
